# Gardian
Repo for my Gardian project, MPD 445.

## Description

Gardian is a physical product - a modular gate system used to prevent pest access, while enabling human access, to gardens. It's designed for gardeners with mobility limitations, gardeners who are short on time, or gardeners who just don't want to mess around with the expense and health risks of chemical pest prevention. 

Gardian is manufactured using recovered ocean-bound plastic.

## Software side

The software side of Gardian is planned to include a website, which includes a responsive Builder Wizard to help users choose the correct components for their setup.
